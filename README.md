# AGENT HQ

Claude Max의 Claude Code를 기본 작업자로, ChatGPT Plus의 Codex를 중요·복잡 작업의 승계자로 사용하는 로컬 우선 멀티 에이전트 제어판입니다.

## 현재 MVP

- 작업 분류 및 Claude 우선 라우팅
- 중요도·복잡도 기준 Codex 승격
- 공급자 한도/오류 발생 시 체크포인트 기반 교대
- SQLite 작업·이벤트 저장과 SSE 이벤트 스트림
- 프로젝트별 실행 폴더, 같은 프로젝트 실행 직렬화
- 실제 실행 전 명시적인 완료 조건 필수화
- 위험 작업 승인 대기열
- 공식 MCP Registry 검색 경계(설계 완료, 연결은 다음 단계)
- 실제 CLI 호출은 기본 비활성화된 모의 실행 모드

화면은 샘플 데이터 기반이며 실행 상태와 아직 연결되지 않았습니다. 반복 실행, 자동 검증, 보안·정책 검토, 팀별 실제 실행은 후속 구현 대상입니다.

## 실행

```powershell
npm test
npm start
```

브라우저에서 `http://localhost:4310`을 엽니다.

실제 CLI 연결은 아직 검증하지 않았습니다. 실행 스위치만 켜도 사용량 상태가 없으므로 작업은 대기합니다. 로그인 상태, 공식 사용량 수집, 권한 정책을 검증하기 전에는 모의 실행을 유지합니다.

```powershell
$env:AGENT_HQ_ENABLE_EXEC='1'
npm start
```

프로젝트 파일은 `projects/<projectId>/`에 생성되며 프로젝트 식별자는 영문·숫자·밑줄·하이픈만 허용합니다. 경로 탈출 및 프로젝트 폴더의 심볼릭 링크를 거부합니다. 폴더 분리는 운영 경계이며 OS 보안 샌드박스를 대체하지 않습니다. 실제 CLI에는 반드시 프로젝트별 실행 폴더를 전달합니다.

실제 실행 요청은 `completionCriteria`에 명시적인 완료 조건을 포함해야 합니다. CLI 종료 코드가 0이어도 `awaiting_verification` 상태로 남으며 자동 완료 처리하지 않습니다. 구독 사용량 수집기는 아직 연결되지 않았고 미확인 상태는 실행을 차단합니다.

상세 결정은 [아키텍처](docs/architecture.md)와 [현황 검증](docs/validation.md)에 있습니다.
