# AGENT HQ 발표 자료 만들기 (open-slide)

open-slide 의 create-slide 스킬(MIT)을 AGENT HQ 팀 방식에 맞게 고친 순서다. 원본은 만들기 전에 사용자에게 네 가지를 묻지만, 팀은 단계 도중에 물을 수 없다. 그래서 기획팀이 미리 정해 작업에 적고, 빠진 것은 아래 기본값으로 정한 뒤 note 에 적는다. 화면 규칙(캔버스·글자 크기·넘침·피할 것)은 slide-authoring 스킬을 따른다.

## 1. 정할 네 가지 (작업에 없으면 기본값)
- 주제와 분위기: 작업에 적힌 대로. 없으면 내용에 맞는 방향 하나를 정해 note 에 적는다.
- 장수: 없으면 5~8장. 표지 1장 + 본론 + 마무리 1장.
- 글자 양: 없으면 "한 장에 핵심 하나, 제목 + 짧은 문장 3줄 이하". 자세한 내용은 발표자 노트(notes)로 뺀다.
- 움직임: 결과물은 PDF 다. Steps·전환 효과는 PDF 에서 모두 펼쳐진 상태로 찍히니, 순서대로 나타나야만 이해되는 구성은 피한다.

## 2. 구조부터
- 쓰기 전에 장마다 "이 장이 말하는 한 문장"을 정한다. 그 문장이 제목이 되거나 제목 바로 아래 온다.
- 같은 모양의 장이 세 번 넘게 이어지지 않게 한다 (표지형·숫자 강조형·비교형·인용형·목록형을 섞는다).
- 숫자·날짜·이름은 작업 폴더의 자료에서 그대로 가져온다. 없는 수치를 만들지 않는다.

## 2-1. 발표 화면 디자인 (첫 시험 덱에서 나온 문제로 정함, 2026-10-01)
- 글자: 1920×1080 기준 제목 72~120px 굵게(700 이상), 본문 32~40px, 가장 작은 설명도 24px 이상. 가는 굵기(300·400)의 큰 제목은 힘이 없다. 엔진이 24px 보다 작은 글자를 알려 준다.
- 화면 채우기: 내용이 위쪽 절반에 몰리고 아래가 비면 미완성으로 보인다. 숫자·도표·그림을 키우거나 좌우 배치로 바꿔 세로 공간을 쓴다. 엔진이 아래 30% 이상 빈 장을 알려 준다.
- 장 구성 섞기: 같은 틀(작은 라벨 + 제목 + 내용)을 계속 쓰지 않는다. 표지형, 큰 숫자형, 좌우 비교형, 타임라인형, 인용·사진형, 표형 가운데 네 가지 이상을 섞고, 어두운 바탕 장을 한두 장 둔다.
- 표지: 제목·한 줄 설명·발표자/날짜만. 장식은 화면 안에서 완결되게 한다 (테두리가 화면 밖으로 잘리거나 의미 없는 점·도형을 두지 않는다).
- 마무리 장: 마지막 장은 "그래서 무엇을 해 달라" 한 문장, 요청 요약 3줄 이하, 연락처나 다음 단계. 표 하나로 끝내지 않는다.
- 그림·약도: 제대로 그릴 수 없는 그림(상자와 점뿐인 약도)은 넣지 않는다. 대신 핵심 숫자나 단어를 크게 둔다.
- 테마: theme-factory 스킬이 있으면 그 테마 하나를 골라 색과 글꼴을 따른다. 엔진 글꼴 묶음(글꼴/)을 쓸 수 있다.

## 3. 파일
- slides/<id>/index.tsx 하나. id 는 역할이 드러나는 한글 이름 (한글·영문 소문자·숫자·-, 띄어쓰기 없이, 예: 구청-소개-발표).
- import 는 '@open-slide/core' 와 'react' 만. 외부 주소·다른 패키지·외부 이미지는 쓰지 않는다. 그림은 인라인 SVG 로 그린다.
- 글꼴은 이 PC 에 설치된 한글 글꼴 목록에서 고른다 (font-family 에 CSS 이름 그대로, 뒤에 'Malgun Gothic', sans-serif).
- ol·ul 의 번호와 점은 기본 스타일이 지워진다. 번호를 글자로 쓰거나 listStyle 을 직접 준다.

## 4. 끝내기 전
- 각 장이 1920×1080 안에 들어가는지 줄 수로 다시 센다 (제목 1~2줄 + 본문 줄 × 줄 높이 + 여백).
- 보고서 JSON 에 "slides":["<id>"] 를 적는다. 엔진이 단계 뒤에 빌드해 발표자료/<id>.pdf 와 장마다 캡처(.hq-screens/슬라이드-<id>-01.png …)를 만든다.
- 다음 단계에 캡처가 있으면 Read 로 직접 열어 잘림·겹침·너무 작은 글자를 먼저 고친다. 넘친 장이나 빌드 오류는 엔진이 피드백으로 준다.
- PPTX 는 만들지 않는다. 대장이 필요하면 PDF 를 바꿔 쓴다.
