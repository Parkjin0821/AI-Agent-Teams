# 파일 이름

- 새 파일은 기능을 나타내는 한글 이름으로 저장한다. 예: `서버.js`, `사용안내.md`, `시작화면.html`.
- 파일을 변경할 때 import, 실행 명령, HTML 링크, 테스트 경로를 함께 수정한다.
- `package.json`, `package-lock.json`, `SKILL.md`, `AGENTS.md`, `.gitignore`, 외부 도구·프레임워크의 고정 이름은 유지한다.
- 외부 라이브러리, 사용자 첨부 원본, 데이터베이스, 완료 근거에 연결된 프로젝트 파일은 일괄 이름 변경하지 않는다. 관련 경로·검증 근거를 이관하는 별도 작업이 필요하다.
- 폴더 이름과 프로젝트 식별자는 현재 경로 계약을 유지한다.
