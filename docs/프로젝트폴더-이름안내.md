# 프로젝트 폴더 이름

- `projects` 안의 프로젝트 폴더는 실제 프로젝트 제목으로 저장한다. 영어 제목에는 `프로젝트-` 접두어를 붙인다.
- 같은 제목은 `(2)`, `(3)`으로 구분한다. Windows에서 사용할 수 없는 문자는 공백으로 정리한다.
- 내부 프로젝트 ID와 API 주소는 유지한다. `projects/.프로젝트경로.json`이 ID와 실제 폴더를 연결한다. 이 파일은 삭제하지 않는다.
- 새 프로젝트를 등록할 때 제목 폴더를 바로 만든다. 모든 실행·결과물·첨부·자동저장은 같은 경로 매핑을 사용한다.
- 프로젝트 제목을 나중에 수정해도 저장된 폴더 이름은 유지하여 실행 경로가 흔들리지 않게 한다.
- 실행 중인 기존 폴더는 이동하지 않는다. 기존 프로젝트 이관은 서버를 끈 상태에서 `node scripts/프로젝트폴더-한글화.mjs --apply`로 진행한다.
- 파일 내용은 변경하지 않는다. 이전·새 폴더 경로와 파일 수·SHA-256 비교 결과는 `data/프로젝트폴더-변경기록`에 남긴다.
- 제목 기록이 없는 기존 폴더는 `기록 없는 프로젝트`로 구분한다.
