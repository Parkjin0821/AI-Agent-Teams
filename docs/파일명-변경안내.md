# 파일명 한글화

- 기존 엔진 소스, 테스트, 실행 스크립트, 안내 문서, 대시보드, 문서 이미지 113개 이름을 한글로 변경했다.
- 실행 시작: `에이전트-시작.cmd` 또는 `npm start`.
- 실행 종료: `에이전트-종료.cmd`.
- 서버 관리: `node scripts/에이전트-관리.mjs status|restart`.
- import, 실행 명령, 대시보드 경로, 문서 링크, 프로젝트 내 Claude 상태 표시 설정을 함께 변경했다.

## 앞으로 생성되는 파일

- 모든 팀의 공통 지침에 한글 파일명 사용 규칙을 넣었다. 도구·프레임워크의 고정 이름은 예외다.
- 디자인 기준: `design/화면설계.md`, `design/화면검토.md`, `design/참고링크.md`.
- 웹 원문: `sources/웹원문-<주소 해시>.txt`. 서로 다른 URL이 같은 이름을 덮어쓰지 않도록 주소 해시를 쓴다.
- 화면 캡처: `.hq-screens/화면-<원본 이름>-<너비>.png`.
- GitHub용 기록: `agent-hq-records/<프로젝트>/작업기록-<해시>.md`.
- 팀 지침은 모델에게 전달되는 규칙이며, 모든 임의 파일 쓰기를 기계적으로 강제하는 기능은 아니다.

## 파일 이름 규칙 문서의 위치

- 규칙은 `docs/파일이름-규칙.md`에 둔다. 저장소 맨 위에 `AGENTS.md`로 두지 않는다.
- 이유: 모든 프로젝트 폴더(`projects/…`)가 이 저장소 안에 있다. Claude Code와 Codex는 작업 폴더 위쪽의 `AGENTS.md`·`CLAUDE.md`를 자동으로 지시로 읽는다. 그래서 엔진은 그런 파일이 위쪽에 있으면 팀 실행을 거부한다(`실행어댑터.js`의 안전장치). 2026-10-01 맨 위에 `AGENTS.md`를 둔 직후, 모든 팀 단계가 "ancestor instruction file"로 거부되는 것을 확인하고 옮겼다.
- Codex에게 작업을 맡길 때는 이 문서를 따르라고 알려 준다.

## 유지한 파일

`package.json`, 외부 라이브러리, Git·Claude 설정의 고정 이름, 데이터베이스, 업로드 원본, 기존 프로젝트의 완료 근거에 연결된 파일은 유지했다. 폴더 이름과 프로젝트 ID도 유지했다.

## 백업

변경 전 원본은 `data/파일명변경-백업/2026-10-01T01-17-32-505Z/`에 `.bak` 확장자로 보존했다. `변경목록.json`에 113개 이전·새 경로가 있다. 현재 파일을 덮어쓰지 말고 이후 변경과 비교해서 필요한 파일만 복구한다.

`scripts/파일명-한글화.mjs`는 최초 이관에 사용한 스크립트다. 재실행용이 아니며 목적지가 존재하면 변경을 거부한다.
