# 짧은 업무보고 서식 보완

- 기존 실제 팀 결과: 업무보고 HTML 미리보기 7페이지.
- 같은 원고로 보완 엔진 실행: 업무보고 2페이지, 회의록 1페이지, 계획서 1페이지.
- 세 문서 모두 구조 검증 통과, 표기 오류와 경고 0, 기존 문서의 날짜·금액·건수 토큰 누락 0.
- 출력: outputs/팀문서-보완검증-1790830733548 (기존 프로젝트 파일 보존).

## 적용 정책
- 업무보고 원고가 2,000자 이하이고 80줄 이하이면 간결한 보고서 서식으로 자동 생성한다. 이 기준은 엔진의 서식 선택 기준이며 페이지 수를 보장하는 기준은 아니다.
- `documents` 요청의 `layout: "full"`은 정식 업무보고 서식을 유지한다. `layout: "compact"`는 업무보고를 간결한 보고서 서식으로 생성한다.
- 실제 사용 서식은 `preset`, 원래 요청은 `requestedPreset`, 선택 결과는 `layout`에 기록한다.
- 문서 내용과 외부 라이브러리는 변경하지 않는다.
- 자동 브라우저의 로컬 파일 접근 제한으로 보완본의 육안 검토는 완료하지 못했다. 한컴 앱 직접 열기도 미검증이다.
- 실행 중 서버에는 재시작 후 반영된다. 다른 이미지 작업을 방해하지 않도록 이번 작업에서는 서버를 재시작하지 않았다.
